# Required screen-recording evidence

The lab requires two **genuine 10-second gameplay screen recordings**. No fabricated or generated video files are included in this package.

## Before changes
1. From this project directory, run `python evidence/baseline_game.py`.
2. On macOS, press **Command-Shift-5** or use QuickTime Player > File > New Screen Recording.
3. Record 10 seconds of the original game's enemy entry/dive curves.
4. Save the captured file as `evidence/before/before.mov`.

## After changes
1. Run `python game.py`.
2. Record 10 seconds of the corrected game and the wave banner. Progress to later waves to demonstrate palette changes and shield charges, if time allows.
3. Save the captured file as `evidence/after/after.mov`.

Also add the actual ChatGPT conversation export or a valid share link if required. `docs/LLM_Prompt_History.pdf` is a prepared summary log, not a verbatim platform export.
