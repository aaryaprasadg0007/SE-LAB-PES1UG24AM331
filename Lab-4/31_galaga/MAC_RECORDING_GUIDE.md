# Mac recording guide for the required evidence

1. Extract the package and open Terminal in the `Lab-4/31_galaga` folder.
2. Run `python3 -m pip install -r requirements.txt` once. Start the baseline with `python3 evidence/baseline_game.py`.
3. Press **Command-Shift-5**, choose to record the game window or a selected region, and capture about 10 seconds. Save the genuine capture as `evidence/before/before.mp4`.
4. Run `python3 game.py` and repeat the capture after the fixes. Save it as `evidence/after/after.mp4`.
5. Keep the game window and moving enemies visible. The generated preview MP4s in the ZIP are illustrative only and are not evidence of a live run.
6. Export the actual ChatGPT conversation using the ChatGPT share/export controls and include the actual file or link requested by the instructor. The included prompt log PDF is a prepared implementation summary, not a verbatim platform export.
