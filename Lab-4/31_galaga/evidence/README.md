# Required recording evidence

The assignment asks for a 10-second gameplay video before the code change and a 10-second video after.

## Before recording

1. Install Pygame using `python -m pip install -r requirements.txt`.
2. Run `python evidence/baseline_game.py`.
3. Start a screen recording on your Mac (QuickTime Player > File > New Screen Recording, or press Command-Shift-5).
4. Record 10 seconds showing the game's original enemy curve behavior.
5. Save the genuine capture as `evidence/before/before.mp4`.

## After recording

1. Run `python game.py`.
2. Record 10 seconds of the corrected gameplay, showing the fixed paths and wave banner.
3. Save the genuine capture as `evidence/after/after.mp4`. Demonstrating later waves and shield charges may require progressing to waves 2 and 3.

The generated MP4s under `previews/` in the downloadable package are marked as visual previews and are not screen recordings. Do not present them as captured gameplay evidence.
